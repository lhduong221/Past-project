# Network Analytics

## Content
- Network metrics on individual node levels and attributes of the network as a whole.
- Node degree, clustering coefficient, Burt's constraint, node betweeness centrality
- Understand network theory (small world theory, etc.) and how they impact the organisation

## Tools
- Python: pandas, numpy, matplotlib, graphviz, etc
